# 적용된 디자인 조합

최신 수정(2026-10-09, 실제 앱 v9): 승인된 v8 시각 표현을 유지하며 페이지별 모션 단계, 콘텐츠 뒤 배치와 순백색 분석 전환을 수정했다. 홈·소개에는 과정 모션이 없고 이력서의 점, 희망 직무의 가지·요소, 채용 공고의 원 형성 순서를 따른다. 같은 위치·크기의 원이 가속하여 동공에 이어지고, 단순한 윤곽과 불규칙한 방사형 홍채가 완성된다. 물결 게이지와 원의 이동·확대 방향은 철회되었다. `/motion-preview?v=8`은 기존 장면 순서의 API 없는 합성 미리보기로 유지한다. [최신 방향과 적용 상태](motion-journey.md)를 참고한다. 이는 로컬 적용 상태이며 배포나 Git 업로드를 뜻하지 않는다.

2026-10-08 사용자가 디자인 비교실에서 선택한 다음 조합을 실제 프로그램에 적용한다.

| 항목                | 선택                                            |
| ------------------- | ----------------------------------------------- |
| 전체 색감           | 포슬린 블루 (`porcelain`)                       |
| 보고서 배치         | 스튜디오 (`studio`)                             |
| 눈 모션             | 사파이어 v8 고정 동공·불규칙한 방사형 섬유       |
| 유리 피라미드       | 클리어 사파이어 (`crystal`)                     |
| 입자 전환·테두리 빛 | 블루 오빗 (`orbit`)                             |

전체 화면은 흰색과 파란색을 중심으로 구성한다. 기본 표면은 `#ffffff`, 바깥 배경은 `#f4f7fc`, 주 강조색은 `#245be0`, 본문은 `#152d50`이다. 오류·주의·근거 부족의 의미를 전달하는 따뜻한 상태 색상은 유지한다.

보고서 첫 화면은 큰 유리 피라미드를 왼쪽에, 실제 지원 공고와 핵심 요약을 오른쪽에 배치한다. 작은 화면에서는 세로로 이어진다. 기존 근거·강점·보완 사항·질문은 보고서 내부 스크롤로 계속 읽는다. 비교실의 가상 인물이나 예시 문구를 실제 보고서에 복사하지 않는다.

이력서 페이지에서는 저장된 이력서가 있더라도 제목과 설명 아래의 푸른 점부터 시작하며, 업로드·저장 중에는 곡선까지만 진행한다. 희망 직무에서는 5개 평가 요소로 갈라진 가지를 유지하고, 채용 공고에서 처음 원을 형성한다. 이전 페이지로 돌아가면 그 페이지의 단계로 즉시 복귀한다. 홈·소개에는 점을 포함한 과정 모션이 없으며, 소개 타이머와 건너뛰기는 유지한다.

모션은 콘텐츠 뒤의 뷰포트 고정 레이어에 배치한다. 관련 입력 칸·패널의 흰색 배경만 불투명도 80%로 처리하여 뒤 모션이 은은하게 비치고, 글자와 버튼은 선명하게 유지한다. 원은 형성 시점부터 최종 동공과 같은 위치·크기를 가지며 스크롤해도 자리가 바뀌지 않는다. 완료된 결과 화면에는 과정 모션과 이 반투명 규칙을 적용하지 않는다.

결과 확인 시 상단 메뉴·단계 표시·본문·버튼이 460ms 동안 사라지며 순백색(`#ffffff`) 배경과 원만 남는다. 원은 함께 페이드되지 않고 같은 위치·크기·회전 위상을 유지한다. 이어 이동이나 확대 없이 회전만 가속하고, 위아래 눈 윤곽을 서로 반대 방향으로 그린다. 양옆은 얇은 주선·보조선과 옅은 푸른 면으로 정리했다. 홍채는 안쪽 경계에서 바깥쪽으로 불규칙한 곡선 섬유들이 자라며 질감을 드러낸다. 링 몸체는 홍채에 녹아들고 테두리 반사광은 분석 대기 중 계속 회전한다. 중앙에는 시각적 진행률을 표시하되 실제 분석 성공 전에는 100%가 되지 않는다. 기존 방사형·물결 렌더러는 소스에 보존하지만, 현재 실제 앱은 공유 v8 렌더러를 사용한다. [과정 모션과 복원 안내](motion-journey.md)를 참고한다.

실제 API 완료와 최소 4초 표시 조건을 함께 충족한 뒤 입자가 보고서 상단 중앙으로 모인다. 빛은 좌우 상단 모서리를 지나 양옆으로 내려가며 사라진다. 긴 문서가 아래로 이어지도록 하단선과 하단 모서리는 그리지 않는다. 실제 스크롤 창의 좌표를 사용하며, 화면 안에 맞추려고 작은 사각형으로 축소하지 않는다. 비회원에게는 실제 점수나 보고서 대신 기존 로그인·회원가입 안내가 나타난다. 분석 실패나 취소를 완료된 보고서로 꾸미지 않는다.

피라미드의 기본 도형은 `#3677e4`, 변화 예시는 `#72c8f5`이다. 네 꼭짓점의 이름과 기존 시연 점수 표시 정책을 유지한다. 색상 선택은 분석 규칙이나 점수 계산을 변경하지 않는다.

상단 메뉴는 소개·이력서·채용공고·모의 지원으로 고정하고, 희망 직무 선택은 별도의 진행표에서만 안내한다. 피라미드 시연 중 숨긴 점수 영역은 높이도 접으며, 시연 버튼과 안내 링크는 내용에 맞는 폭으로 나란히 배치한다.

모션의 선택된 색상 값은 `src/shared/design/selected-theme.js`에서 관리한다. `/design-lab`은 다른 조합을 비교할 때 사용할 수 있으며, 비교실에서 선택을 바꾸는 것만으로 실제 프로그램의 디자인이 바뀌지는 않는다.
