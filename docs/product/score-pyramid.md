# 이력서 입체 분석과 시연 점수

기존 보고서의 그래픽 위치에 투명한 정사면체(삼각뿔)를 표시합니다. 네 꼭짓점은 각 축의 100점이며, 중심에서 꼭짓점까지의 거리에 점수 비율을 곱해 내부 도형을 만듭니다. 도형의 부피는 종합 점수가 아닙니다.

## 현재 화면: 프론트엔드 시연

사용자 요청에 따라 네 축은 **이력서 완성도 · 직무 적합도 · 지원 자격 충족도 · 실무 경쟁력**입니다. 현재 값은 임시 랜덤 점수이며 화면에 **시연용 점수 · 실제 평가와 무관**이라고 표시합니다. 이력서 문장, 개인정보, 서버의 기존 70/20/10 점수에서 새 점수를 추론하지 않습니다. 같은 보고서 객체를 다시 렌더링하면 같은 값을 유지하고, 새로 불러온 보고서는 새로운 시연 값이 될 수 있습니다.

금색 내부 도형은 현재 시연 값입니다. 보완 예시를 선택하면 시연용으로 준비한 다른 값에 맞춰 모양이 부드럽게 변하고 색도 붉은 계열로 전환합니다. 이는 보완 동작의 예시이며 실제 개선 점수나 합격 가능성을 예측하지 않습니다. 저장된 이력서와 서버 보고서는 변경하지 않습니다. 근거가 부족한 항목의 베이지색 표시는 유지합니다.

실제 점수는 백엔드 담당자가 산정 정책과 API를 확정한 뒤 연결합니다. 기존 서버 계산은 호환성을 위해 남아 있지만 새 네 축으로 이름만 바꿔 표시하지 않습니다. 하위 항목의 실제 점수나 새로운 종합 점수는 만들지 않습니다.

## 제공된 평가 기준: 백엔드 연결 참고

| 큰 항목 | 하위 평가 항목 | 참고 가중치 |
|---|---|---:|
| 이력서 완성도 | 경험 설명의 구체성 | 0.40 |
| 이력서 완성도 | 성과 근거의 명확성 | 0.35 |
| 이력서 완성도 | 구성과 가독성 | 0.25 |
| 직무 적합도 | 핵심 기술 일치도 | 0.45 |
| 직무 적합도 | 담당 업무 연관성 | 0.40 |
| 직무 적합도 | 우대 역량 부합도 | 0.15 |
| 지원 자격 충족도 | 관련 경력 충족도 | 0.60 |
| 지원 자격 충족도 | 학력·전공 충족도 | 0.25 |
| 지원 자격 충족도 | 기타 필수조건 충족도 | 0.15 |
| 실무 경쟁력 | 업무 규모·난도 경쟁력 | 0.35 |
| 실무 경쟁력 | 운영·문제 해결 경쟁력 | 0.35 |
| 실무 경쟁력 | 역할·책임 수준 경쟁력 | 0.30 |

사용자가 제시한 축별 참고식은 `100 × ∏((하위 점수 / 100) ^ 가중치)`입니다. 현재 시연 점수는 이 식으로 계산하지 않습니다. 공고에 없는 조건, 근거가 부족한 경우, 경력 중복 기간, 실제 지원자 비교 자료의 유무 등은 백엔드 담당자가 판단할 부분입니다. 네 축을 합치는 종합식은 제시되지 않았으므로 추가하지 않습니다.

## 조작과 눈 모션

피라미드는 천천히 회전하며 마우스 이동으로 시점이 반응하고 휠로 확대·축소합니다. 조작 버튼은 그래픽 위에 표시하지 않습니다. 키보드 방향키와 +/-도 지원하고, 화면 밖·숨겨진 탭에서는 반복 렌더링을 멈춥니다. 모션 감소 설정에서는 자동 회전·점수 변형을 줄입니다. WebGL이 없으면 원근 SVG와 같은 숫자를 표시합니다. 보고서는 브라우저 열람 전용이며 인쇄 버튼은 없고 인쇄 CSS에서 숨깁니다.

눈 모션은 답변 제출 후 표시합니다. 최소 4초와 실제 API 응답 완료를 모두 기다리며, 동공은 어둡게 유지하고 황금선이 중앙에서 밖으로 각기 다른 속도로 자랍니다. 12개 하위 항목은 분석을 시작할 때마다 서로 다른 황금선 위치에 배정됩니다. 실행 중 배정은 고정되고 팝업 게이지와 연결점은 해당 선의 성장에 맞춰 움직입니다. 모든 팝업을 동시에 띄우지 않고 순환해서 보여줍니다. 이것은 시각적 준비 진행률이며 하위 평가별 실제 서버 진행률이나 점수가 아닙니다.

## 편집 위치

- 시연 값·하위 항목: `src/features/analysis/demo-score-data.js`
- 보고서와 값 연결: `report.js`, `status-radar-data.js`, `status-radar.js`
- 피라미드 기하·재질: `tools/matching-eye/src/score-pyramid.ts`, `pyramid-geometry.ts`
- 눈의 배치·진행률: `tools/matching-eye/src/analysis-*.ts`

TypeScript 수정 후 `tools/matching-eye`에서 `npm run build`로 포함된 번들을 갱신합니다. 개인 API 키나 DB 설정은 이 시연 데이터에 넣지 않습니다.
